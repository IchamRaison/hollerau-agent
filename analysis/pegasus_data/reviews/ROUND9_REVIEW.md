## Idées nouvelles classées par gain × confiance

Un point signifie +0,01 du score d’un cas ; sur dix cas également pondérés, +1 point sur un cas ajoute +0,1 point de moyenne. Les plages incluent zéro et désignent un gain à **viser si un pas supplémentaire est obtenu**, pas une prédiction issue d’un replay. Leur plafond est motivé par un pas observé ou une fraction de l’écart au record. Les gains ne s’additionnent pas entre idées concurrentes. Le rang utilise plafond de plage × confiance **ordinale 1–5**, pas une probabilité.

### 1. Validation commerciale avant final_offer

Mécanisme : Sur un signal explicite de revue interne/politique commerciale, demander une validation du meilleur prix sur les mêmes feuilles, une fois, dans le contre-mail existant.

Preuve : P05 : 30,50 → 28,77 au tour 2 ; backoffice « Checked: give the rest of the step ». P02 : les questions déclenchent Credit Control, jamais une demande explicite au commercial manager.

Gain visé 0–8 points/cas ; confiance 2/5 ; priorité 16. Le signal P05 valide le rôle de la revue interne, pas l’effet causal de notre nouvelle phrase. Un pas supplémentaire de 0,50 € vaut environ 3 000 € sur P02, soit ≈6 points avant variation de relationship.

Risque : Une demande au manager peut durcir la position ou répéter un circuit déjà terminé. Une seule demande, avant finale, réserve de tours.

Test sandbox gratuit possible : D02 oui, D01 seulement si signal interne ; mesurer prix/termes et backoffice, pas seulement la présence du mot manager.

### 2. BAFO RFQ au deuxième contre-mail

Mécanisme : Lorsque deux offres debout légales existent, demander une BAFO une fois avant agreed/final, sur les feuilles déjà calculées ; garder les devis disponibles jusqu’à attribution.

Preuve : P05 : les vrais devis rivaux sont déclarés pris en compte ; Riedl cède 0,50 € après nouveaux devis. Les gagnants restent 28,77 et les relances après agreed ne les font plus bouger.

Risque : Le mot final peut écourter le processus ; déclenchement après un premier contre, sans nouvel aller-retour et sans rouvrir les accords.

Test sandbox gratuit possible : D02 oui (RFQ), D01 non ; tester BAFO seul, comparer meilleur C réalisable, tours et retraits.

Risque : Une ancre plus haute peut donner un prix final plus haut ; le délai standard comporte une pénalité de retard déjà intégrée. Les feuilles restent légales et au budget.

Test sandbox gratuit possible : D01/D02 ne reproduisent pas la double contrainte observée ; test complet impossible sur ces cas. Test synthétique local transférable, puis un essai practice autorisé ultérieurement.

Risque : L’index peut être obligatoire et coûter davantage qu’il ne rapporte ; respecter les options et la marge relationship. Ne pas renégocier la structure gagnante seulement pour baisser le prix affiché.

### 10. Question d’approbation sans feuille, à titre exceptionnel

Mécanisme : Si une validation interne est explicitement en attente et aucun prix nouveau n’est demandé, une seule question ciblée peut obtenir le reste d’un pas sans concession supplémentaire.

Preuve : P05 montre le circuit interne ; zéro question sans feuille dans l’échantillon open pratique analysé. Les questions d’attente post-agreed n’améliorent pas les gagnants.

Gain visé 0–2 points/cas ; confiance 1/5 ; priorité 2. Gain hypothétique 0–2, faute de réponse open contrôlée ; à évaluer après les essais inline qui n’ajoutent aucun tour.

Risque : Consomme un tour et peut déclencher final_offer ; ne pas utiliser comme temporisation systématique.

### 11. Nibble de termes au même prix, avec maintien de l’accord

Mécanisme : Une seule demande d’un terme réellement nouveau après agreed, au même prix, uniquement si le fournisseur a explicitement proposé ce levier et peut maintenir son accord.

Preuve : P03 kit, P07 et P05 réaffirment l’accord après de fortes nouvelles demandes. Aucune amélioration post-agreed observée dans ces runs ; la relance post-final P02 finit sans deal.

Gain visé 0–1 points/cas ; confiance 1/5 ; priorité 1. Gain visé très faible, 0–1 ; ne pas réactiver le nibbling actuel ni la relance finale comme réglage global.

Risque : Retrait de l’accord ou finale prématurée ; réciprocité à démontrer, pas d’accord préservé garanti par une phrase.

Test sandbox gratuit possible : D01/D02 oui comme protocole, aucune extrapolation de sécurité aux corporates.

Pistes évaluées sans nouveau rendement démontré :

- **Volume/durée explicites** : déjà livrés dans r9 ; P02/P18 demandent encore les chiffres malgré la phrase. La nouveauté utile est l’approbation d’un échange conditionnel concret, pas répéter “binding volume”.

- **Ton allemand / formulations chaleureuses** : les signatures et formules standard coexistent avec des scores très différents. Pas de comparaison contrôlée, zéro gain crédible attribuable au ton seul.
